# Licensing and provenance

This private development repository aggregates patches to multiple upstream
projects. It does not relicense those projects under a single new license.
Retain their licenses, notices and attribution when using or distributing
modified sources. Upstream repositories and revisions are recorded in the
manifest and baseline inventory.

Publishing source patches is distinct from redistributing proprietary ROM
dependencies. No proprietary binary payloads or binary Git patches are stored
here. Binary recipes describe a reproducible operation on a separately
obtained, hash-checked input; they do not grant rights to obtain or distribute
that input.

Repository visibility does not establish redistribution rights. Review
applicable upstream terms before changing this repository to public or
publishing ROM binaries. No blanket copyright clearance is asserted.
